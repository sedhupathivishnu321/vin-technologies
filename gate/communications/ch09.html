GATE Focus

9.1 Information and entropy

The information in an event of probability \(p\) is \(I=-\log_2p\) bits (\(-\ln p\) in nats). For a discrete source with symbol probabilities \(p_i\):

Entropy

\(H(X)=-\displaystyle\sum_ip_i\log_2p_i\) bits/symbol.   \(0\le H\le\log_2M\), with equality \(H=\log_2M\) iff all \(M\) symbols are equiprobable; \(H=0\) for a deterministic source.
Binary entropy function: \(H_b(p)=-p\log_2p-(1-p)\log_2(1-p)\), maximum \(1\) at \(p=\tfrac12\); \(H_b(0.1)=0.469\).
Source information rate \(R=r\,H\) (bits/s) with \(r\) symbols/s.
Extension: \(H(X^n)=nH(X)\) for independent symbols.

Solved Example

\(\{1/2,1/4,1/8,1/8\}\): \(H=\tfrac12(1)+\tfrac14(2)+2\cdot\tfrac18(3)=1.75\) bits. Four equiprobable symbols: \(2\) bits. Three equiprobable: \(\log_23=1.585\).

9.2 Joint, conditional entropy and mutual information

Relations

\(H(X,Y)=H(X)+H(Y|X)=H(Y)+H(X|Y)\).   \(H(X|Y)\le H(X)\) (conditioning reduces entropy).
Mutual information: \(I(X;Y)=H(X)-H(X|Y)=H(Y)-H(Y|X)=H(X)+H(Y)-H(X,Y)=\displaystyle\sum p(x,y)\log_2\frac{p(x,y)}{p(x)p(y)}\ge0\); zero iff independent; symmetric.
Data-processing inequality: for a Markov chain \(X\to Y\to Z\), \(I(X;Z)\le I(X;Y)\).

Solved Example

Joint pmf \(p(0,0)=p(1,1)=0.4\), \(p(0,1)=p(1,0)=0.1\): \(H(X)=H(Y)=1\), \(H(X,Y)=1.722\), \(I(X;Y)=1+1-1.722=0.278\) bits.

9.3 Channel capacity

The capacity is the maximum mutual information over input distributions, \(C=\max_{p(x)}I(X;Y)\) bits per channel use. Channel coding theorem: reliable communication (arbitrarily small error) is possible at any rate \(R<C\) and impossible for \(R>C\).

Standard channels

Noiseless binary: \(C=1\).   BSC (crossover \(p\)): \(C=1-H_b(p)\); \(p=0.1\Rightarrow0.531\); \(p=0.5\Rightarrow0\).
BEC (erasure probability \(\varepsilon\)): \(C=1-\varepsilon\) (achieved by uniform input).
AWGN (Shannon–Hartley): \(C=B\log_2\left(1+\dfrac SN\right)=B\log_2\left(1+\dfrac{S}{N_0B}\right)\) bits/s.
Infinite bandwidth: \(C_\infty=\dfrac{S}{N_0\ln2}=1.44\,\dfrac S{N_0}\).
Spectral efficiency \(\eta=R_b/B\) at \(R_b=C\): \(\dfrac{E_b}{N_0}\ge\dfrac{2^\eta-1}{\eta}\); as \(\eta\to0\): \(E_b/N_0\ge\ln2=0.693\) (\(-1.59\) dB), the Shannon limit.
\(\eta=1\Rightarrow0\) dB; \(\eta=2\Rightarrow1.5\) (\(1.76\) dB).

Solved Example

Telephone channel \(B=3\) kHz, \(\text{SNR}=30\) dB \((1000)\): \(C=3000\log_2(1001)=29.9\) kbps.
To send \(10\) kbps in \(B=2\) kHz: \(\text{SNR}\ge2^{5}-1=31\) (\(14.9\) dB).
\(S/N_0=10^4\) Hz: \(C_\infty=14.4\) kbps.

For the Gaussian channel the capacity-achieving input is Gaussian; for a continuous source with variance \(\sigma^2\) the differential entropy is maximised by the Gaussian: \(h=\tfrac12\log_2(2\pi e\sigma^2)\). Increasing bandwidth increases capacity only up to the limit \(C_\infty\) (power-limited regime); increasing power gives only a logarithmic gain (bandwidth-limited regime).

9.4 Source coding

Representing source symbols by binary codewords of length \(l_i\). Average length \(\bar L=\sum_ip_il_i\).

Source coding theorem

Prefix (instantaneous) codes exist iff Kraft’s inequality holds: \(\displaystyle\sum_i2^{-l_i}\le1\).
\(H(X)\le\bar L<H(X)+1\) (optimal prefix code).   Efficiency \(\eta=\dfrac{H}{\bar L}\), redundancy \(1-\eta\).
Block coding of \(n\) symbols: \(H\le\bar L_n/n<H+1/n\).

  • Shannon–Fano: sort by probability and split into near-equal-probability groups recursively.
  • Huffman: repeatedly combine the two least probable symbols; yields an optimal prefix code (not unique but with the same \(\bar L\)).
  • Lempel–Ziv: universal, dictionary-based, no probabilities needed (used in zip, GIF). Run-length coding for long runs.
Huffman

\(p=\{0.4,0.3,0.2,0.1\}\): merge \(0.2+0.1=0.3\), then \(0.3+0.3=0.6\), then with \(0.4\). Lengths \((1,2,3,3)\): \(\bar L=0.4+0.6+0.6+0.3=1.9\) bits. \(H=1.846\), efficiency \(97.2\%\). A fixed-length code needs \(2\) bits.
Kraft check: \(2^{-1}+2^{-2}+2^{-3}+2^{-3}=1\) (complete code).

Rate–distortion: for lossy compression the minimum rate \(R(D)\) needed to reproduce the source with distortion at most \(D\); for a Gaussian source with variance \(\sigma^2\) and mean-square distortion \(D\): \(R(D)=\tfrac12\log_2(\sigma^2/D)\) for \(D\le\sigma^2\).

Conceptual Trap

(i) \(\log_2\) for bits; do not mix with \(\ln\). (ii) Entropy is maximal for equiprobable symbols. (iii) Huffman codes need not be unique, yet the average length is. (iv) The Shannon limit \(-1.59\) dB is for infinite bandwidth and \(R_b\to0\); practical systems need more. (v) Mutual information is non-negative and symmetric.

GATE Shortcut

Entropy of dyadic probabilities: \(\sum p_i\,l_i\) with \(l_i=-\log_2p_i\). BSC capacity \(1-H_b(p)\). Shannon–Hartley: \(C=B\log_2(1+\text{SNR})\) (\(\text{SNR}\) linear). \(\eta\) bit/s/Hz needs \(\text{SNR}\ge2^\eta-1\).

9.5 GATE problems

GATE 1-Mark Problems

Q1. The entropy of a source emitting four equiprobable symbols is (A) 1 bit (B) 2 bits (C) 4 bits (D) 0.5 bit.

Q2. The capacity of a BSC with \(p=0.5\) is (A) 1 (B) 0.5 (C) 0 (D) \(\infty\).

Q3. The Shannon limit on \(E_b/N_0\) (infinite bandwidth) is (A) 0 dB (B) \(-1.59\) dB (C) 3 dB (D) \(-3\) dB.

Q4. Kraft’s inequality \(\sum2^{-l_i}\le1\) is necessary and sufficient for a (A) uniquely decodable code (B) prefix code to exist (C) Huffman code (D) fixed-length code only.

Answers: Q1 (B). Q2 (C). Q3 (B). Q4 (B) (also holds for uniquely decodable codes).

GATE 2-Mark Problems

Q5. The entropy of \(\{1/2,1/4,1/8,1/8\}\) is (A) 1.5 (B) 1.75 (C) 2 (D) 1.25 bits.

Q6. A telephone channel with \(B=3\) kHz and SNR 30 dB has capacity about (A) 9.9 kbps (B) 19.9 kbps (C) 29.9 kbps (D) 90 kbps.

Q7. A BSC with crossover probability 0.1 has capacity (A) 0.469 (B) 0.531 (C) 0.9 (D) 0.1 bit/use.

Answers: Q5 (B). Q6 (C). Q7 (B): \(1-0.469\).

Numerical Answer Type (NAT)

Q8. Average length (bits) of the Huffman code for \(\{0.4,0.3,0.2,0.1\}\): .

Q9. Capacity (bit/use) of a BEC with erasure probability 0.25: .

Q10. Minimum SNR (dB, one decimal) to send 10 kbps over a 2 kHz AWGN channel: .

Answers: Q8: 1.9. Q9: 0.75. Q10: \(2^5-1=31\to14.9\) dB.

Multiple Select (MSQ)

Q11. Select the true statements. (A) \(I(X;Y)\ge0\). (B) \(H(X|Y)\le H(X)\). (C) Huffman coding is optimal among prefix codes. (D) Doubling the bandwidth always doubles the capacity.

Answers: Q11: (A), (B), (C).

Chapter Test

T1. \(H(0.9,0.1)\).   T2. \(C_\infty\) in terms of \(S/N_0\).   T3. Can code lengths \((1,2,2,3)\) form a prefix code?

Answers: T1: 0.469. T2: \(1.44S/N_0\). T3: \(0.5+0.25+0.25+0.125=1.125>1\): no.
