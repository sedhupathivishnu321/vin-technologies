Chapter 21

Controllability and Observability

GATE Focus

Rank tests for controllability and observability; parameter values that destroy them; relation with pole–zero cancellation and minimal realisations; canonical forms. A regular 1-mark and 2-mark topic.

21.1 Core concept

  • Controllability: the state can be driven from any \(x_0\) to any \(x_1\) in finite time by a suitable input \(u(t)\). It is about the pair \((A,B)\): whether the input can reach every mode.
  • Observability: the initial state \(x_0\) can be determined from the output \(y(t)\) (with \(u\) known) over a finite interval. It is about \((A,C)\): whether every mode is visible at the output.

21.2 Rank tests (Kalman)

Key Formulae

Controllability matrix: \(Q_c=[\,B\ \ AB\ \ A^2B\ \cdots\ A^{n-1}B\,]\); controllable \(\iff\mathrm{rank}\,Q_c=n\).
Observability matrix: \(Q_o=\begin{bmatrix}C\\CA\\CA^2\\\vdots\\CA^{n-1}\end{bmatrix}\); observable \(\iff\mathrm{rank}\,Q_o=n\).
For a single input (\(Q_c\) square): controllable \(\iff\det Q_c\ne0\); single output: observable \(\iff\det Q_o\ne0\).

Duality: \((A,B)\) is controllable \(\iff(A^T,B^T)\) is observable.

Why \(B,AB,\dots\)?

\(x(t)=e^{At}x_0+\int_0^te^{A(t-\tau)}Bu(\tau)d\tau\). By Cayley–Hamilton \(e^{At}=\sum_{k=0}^{n-1}\alpha_k(t)A^k\), so the reachable states lie in the span of \(\{B,AB,\dots,A^{n-1}B\}\): they cover \(\mathbb R^n\) exactly when this set has rank \(n\). Observability follows by duality (output \(=Ce^{At}x_0\) contains \(C,CA,\dots\)).

21.3 Gilbert’s test (diagonal form)

If \(A=\mathrm{diag}(\lambda_1,\dots,\lambda_n)\) with distinct \(\lambda_i\): controllable iff no row of \(B\) is zero; observable iff no column of \(C\) is zero. (Repeated eigenvalues need the Jordan-form version or a rank test; a single input cannot control two identical modes.)

21.4 Canonical forms and transfer function

  • The controllable canonical form is always controllable; the observable canonical form is always observable.
  • \(G(s)=C(sI-A)^{-1}B\) has a pole–zero cancellation iff the realisation is not both controllable and observable. The realisation is minimal (order \(=\) degree of the reduced \(G(s)\)) iff it is controllable and observable.
  • Uncontrollable or unobservable modes do not appear in \(G(s)\), but they appear in the state response (internal stability requires them to be stable as well).
  • Kalman decomposition splits the state into: controllable+observable (in \(G\)), controllable+unobservable, uncontrollable+observable, uncontrollable+unobservable.

Design relevance: arbitrary pole placement by state feedback \(u=-Kx\) requires controllability; a state observer (estimator) requires observability.

21.5 Solved examples

Controllable and observable

\(A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}\), \(B=\begin{bmatrix}0\\1\end{bmatrix}\), \(C=[1\ 0]\). \(AB=\begin{bmatrix}1\\-3\end{bmatrix}\), \(Q_c=\begin{bmatrix}0&1\\1&-3\end{bmatrix}\), \(\det=-1\ne0\): controllable. \(CA=[0\ 1]\), \(Q_o=\begin{bmatrix}1&0\\0&1\end{bmatrix}\), \(\det=1\): observable.

Unobservable

Same \(A,B\) but \(C=[1\ 1]\): \(CA=[-2\ -2]\), \(Q_o=\begin{bmatrix}1&1\\-2&-2\end{bmatrix}\), \(\det=0\): unobservable. Indeed \(G=\dfrac{s+1}{(s+1)(s+2)}\): the pole at \(-1\) is cancelled.

Uncontrollable

\(A=\mathrm{diag}(-1,-2)\), \(B=\begin{bmatrix}1\\0\end{bmatrix}\): \(Q_c=\begin{bmatrix}1&-1\\0&0\end{bmatrix}\), rank \(1\). The mode at \(-2\) (row of \(B\) is \(0\)) cannot be excited; \(G=\dfrac{1}{s+1}\).

Parameter

\(A=\begin{bmatrix}1&0\\0&2\end{bmatrix}\), \(B=\begin{bmatrix}1\\k\end{bmatrix}\): \(AB=\begin{bmatrix}1\\2k\end{bmatrix}\), \(\det Q_c=2k-k=k\). Controllable iff \(k\ne0\).

Repeated eigenvalues

\(A=\begin{bmatrix}-1&0\\0&-1\end{bmatrix}\), \(B=\begin{bmatrix}1\\1\end{bmatrix}\): \(AB=-B\), \(\mathrm{rank}\,Q_c=1\): uncontrollable although no row of \(B\) is zero (Gilbert’s test does not apply).

Third order

\(A=\begin{bmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{bmatrix}\), \(B=\begin{bmatrix}0\\0\\1\end{bmatrix}\) (CCF): \(Q_c=\begin{bmatrix}0&0&1\\0&1&-6\\1&-6&25\end{bmatrix}\), \(\det=-1\): controllable.

21.6 Physical interpretation

Uncontrollable mode: the input cannot influence it (e.g. a tank isolated from the pump). Unobservable mode: it evolves without showing up at the output (e.g. a sensor blind to one tank). Such hidden modes are harmless if stable but dangerous if unstable, even though \(G(s)\) looks fine.

GATE Shortcut

Two states, single input/output: compute \(\det[B\ \ AB]\) and \(\det\begin{bmatrix}C\\CA\end{bmatrix}\). Diagonal form with distinct eigenvalues: check \(B\)’s rows and \(C\)’s columns. Pole–zero cancellation in \(G(s)\) means loss of at least one of the two properties.

Conceptual Trap

(i) Controllability/observability are properties of the realisation, not of \(G(s)\). (ii) Controllable does not imply observable, and vice versa. (iii) Equal eigenvalues with one input \(\Rightarrow\) uncontrollable if \(A\) is diagonal. (iv) The controllability matrix uses \(A^kB\), the observability matrix uses \(CA^k\): do not swap the order. (v) \(D\) has no effect.

GATE 1-Mark Problems

Q1. A system with \(\mathrm{rank}[B\ AB\ \dots]<n\) is (A) uncontrollable (B) unobservable (C) unstable (D) nonlinear.

Q2. The controllable canonical form is (A) always observable (B) always controllable (C) never controllable (D) always uncontrollable.

Q3. Pole–zero cancellation in \(G(s)\) implies the state model is (A) controllable and observable (B) not both controllable and observable (C) unstable (D) nonlinear.

Answers: Q1 (A). Q2 (B). Q3 (B).

GATE 2-Mark Problems

Q4. \(A=\begin{bmatrix}-1&0\\0&-3\end{bmatrix}\), \(B=\begin{bmatrix}1\\0\end{bmatrix}\), \(C=[1\ 1]\): (A) controllable and observable (B) controllable only (C) observable only (D) neither.

Q5. \(A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}\), \(B=\begin{bmatrix}1\\-1\end{bmatrix}\): the system is (A) controllable (B) uncontrollable (C) unstable-only (D) not defined.

Answers: Q4 (C): \(B\) has a zero row (mode \(-3\) uncontrollable); \(C\) has no zero column: observable. Q5 (B): \(AB=\begin{bmatrix}-1\\-2+3\end{bmatrix}=\begin{bmatrix}-1\\1\end{bmatrix}=-B\), so rank \(1\): uncontrollable (\(B\) is an eigenvector for \(\lambda=-1\)).

Numerical Answer Type (NAT)

Q6. \(A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}\), \(B=\begin{bmatrix}0\\1\end{bmatrix}\): \(\det Q_c=\) .

Q7. For \(A=\begin{bmatrix}1&0\\0&2\end{bmatrix}\), \(B=\begin{bmatrix}1\\k\end{bmatrix}\), the value of \(k\) making the system uncontrollable is .

Answers: Q6: \(-1\). Q7: \(0\).

Multiple Select (MSQ)

Q8. Which are correct? (A) Duality relates controllability and observability (B) A minimal realisation is controllable and observable (C) CCF is always observable (D) Unobservable modes do not appear in \(G(s)\).

Answers: Q8: (A), (B), (D).

Previous-year pattern

\(G(s)=\dfrac{s+2}{(s+1)(s+2)(s+3)}\) has a pole–zero cancellation at \(-2\): any third-order realisation is uncontrollable or unobservable (or both); the minimal realisation has \(2\) states, \(G=\dfrac1{(s+1)(s+3)}\).

Chapter Test

T1. State the controllability rank condition and the reason for \(A^{n-1}B\) as the last column.
T2. \(A=\begin{bmatrix}0&1\\0&0\end{bmatrix}\), \(B=\begin{bmatrix}0\\1\end{bmatrix}\), \(C=[1\ 0]\). Controllable? Observable?

Answers: T1: rank \([B\ AB\ \dots A^{n-1}B]=n\); higher powers add no new directions (Cayley–Hamilton). T2: \(Q_c=\begin{bmatrix}0&1\\1&0\end{bmatrix}\), det \(-1\): controllable; \(Q_o=\begin{bmatrix}1&0\\0&1\end{bmatrix}\): observable (\(G=1/s^2\)).

One-Page Revision
  • Controllable \(\iff\mathrm{rank}[B\ AB\dots A^{n-1}B]=n\); observable \(\iff\mathrm{rank}[C;CA;\dots;CA^{n-1}]=n\).
  • Diagonal, distinct eigenvalues: rows of \(B\) and columns of \(C\) non-zero.
  • Pole–zero cancellation \(\iff\) not both; minimal \(\iff\) both.
  • Pole placement needs controllability; observer needs observability.
