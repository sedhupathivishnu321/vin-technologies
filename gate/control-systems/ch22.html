How to use this chapter

Forty-eight one-mark problems, four per topic, in the order of the syllabus. Target: \(\le 1\) minute each. Every problem is original and written in the style of GATE ECE Control Systems questions. Answers with one-line reasons follow each block.

22.1 Basic control-system concepts

Set 22.1

Q1. Which system is nonlinear? (A) \(y=3x\) (B) \(y=\dot x\) (C) \(y=x^2\) (D) \(y=\int x\,dt\).

Q2. Which is time-varying? (A) \(\dot y+2y=x\) (B) \(\dot y+ty=x\) (C) \(y=5x(t-1)\) (D) \(y=\dot x\).

Q3. A system whose output depends only on the present input is (A) dynamic (B) static (C) non-causal (D) unstable.

Q4. Negative feedback typically (A) reduces bandwidth (B) increases bandwidth (C) leaves bandwidth unchanged (D) makes it infinite.

Answers: Q1 (C). Q2 (B). Q3 (B). Q4 (B).

22.2 Transfer functions

Set 22.2

Q5. The transfer function of an ideal integrator is (A) \(s\) (B) \(1/s\) (C) \(1/s^2\) (D) \(1\).

Q6. If \(h(t)=e^{-2t}u(t)\) then \(G(s)=\) (A) \(\dfrac1{s-2}\) (B) \(\dfrac1{s+2}\) (C) \(\dfrac2s\) (D) \(2s\).

Q7. The order of \(\dfrac{s+3}{s^2(s+1)(s+4)}\) is (A) 1 (B) 2 (C) 3 (D) 4.

Q8. The DC gain of \(\dfrac{6(s+1)}{(s+2)(s+3)}\) is (A) 6 (B) 1 (C) 3 (D) 0.

Answers: Q5 (B). Q6 (B). Q7 (D). Q8 (B): \(6/6\).

22.3 Block diagrams

Set 22.3

Q9. \(G_1,G_2\) cascaded inside a unity negative feedback loop give (A) \(\dfrac{G_1G_2}{1+G_1G_2}\) (B) \(\dfrac{G_1+G_2}{1+G_1G_2}\) (C) \(\dfrac{G_1G_2}{1-G_1G_2}\) (D) \(G_1G_2\).

Q10. Two parallel feedback paths \(H_1,H_2\) (both negative) around \(G\): (A) \(\dfrac{G}{1+GH_1H_2}\) (B) \(\dfrac{G}{1+G(H_1+H_2)}\) (C) \(\dfrac{G}{1-G(H_1+H_2)}\) (D) \(\dfrac{G}{1+GH_1}+\dfrac{G}{1+GH_2}\).

Q11. A summing point is moved from before to after block \(G\); the added branch gets (A) \(G\) (B) \(1/G\) (C) \(1\) (D) \(-G\).

Q12. Positive feedback: \(C/R=\) (A) \(\dfrac{G}{1+GH}\) (B) \(\dfrac{G}{1-GH}\) (C) \(\dfrac{GH}{1-G}\) (D) \(\dfrac{1}{1-GH}\).

Answers: Q9 (A). Q10 (B). Q11 (A). Q12 (B).

22.4 Signal-flow graphs

Set 22.4

Q13. Two non-touching loops with gains \(-0.3\) and \(-0.2\): \(\Delta=\) (A) \(0.5\) (B) \(1.5\) (C) \(1.56\) (D) \(1.44\).

Q14. In \(\Delta_k\) the loops removed are those that (A) touch path \(k\) (B) do not touch path \(k\) (C) are positive (D) have gain \(<1\).

Q15. One forward path \(P=5\) touching a single loop \(L=-0.25\): \(T=\) (A) \(4\) (B) \(6.67\) (C) \(1.25\) (D) \(5\).

Q16. Mason’s formula applies to (A) linear systems (B) nonlinear systems (C) time-varying only (D) digital only.

Answers: Q13 (C): \(1+0.3+0.2+0.06\). Q14 (A). Q15 (A): \(5/1.25\). Q16 (A).

22.5 Time response

Set 22.5

Q17. \(\zeta=0.5\): peak overshoot is about (A) \(4.3\%\) (B) \(16.3\%\) (C) \(25\%\) (D) \(50\%\).

Q18. Poles at \(-3\pm j4\): \(2\%\) settling time is (A) \(0.75\) (B) \(1.33\) (C) \(2.66\) (D) \(4\) s.

Q19. A second-order system has \(\omega_d=\pi\) rad/s. Peak time is (A) \(0.5\) (B) \(1\) (C) \(2\) (D) \(\pi\) s.

Q20. First-order lag with \(\tau=0.1\) s: \(2\%\) settling time is (A) \(0.1\) (B) \(0.3\) (C) \(0.4\) (D) \(1\) s.

Answers: Q17 (B). Q18 (B): \(4/3\). Q19 (B): \(\pi/\omega_d\). Q20 (C).

22.6 Steady-state error

Set 22.6

Q21. Unity feedback, type 1: error to unit ramp is (A) \(0\) (B) \(1/K_v\) (C) \(\infty\) (D) \(1/(1+K_p)\).

Q22. Type 0, \(K_p=9\): step error is (A) \(0.9\) (B) \(0.1\) (C) \(0\) (D) \(1/9\).

Q23. Type 2: error to \(t^2/2\) input is (A) \(0\) (B) \(\infty\) (C) \(1/K_a\) (D) \(1/K_v\).

Q24. \(G=\dfrac{10}{s(s+5)}\): \(K_v=\) (A) \(2\) (B) \(5\) (C) \(10\) (D) \(0.5\).

Answers: Q21 (B). Q22 (B): \(1/(1+9)\). Q23 (C). Q24 (A).

22.7 Stability

Set 22.7

Q25. \(s^3+2s^2+3s+4=0\) has (A) 0 RHP roots (B) 1 (C) 2 (D) 3.

Q26. \(s^4+s^3+s^2+s+1=0\) has (A) 0 (B) 1 (C) 2 (D) 4 RHP roots.

Q27. A row of zeros in Routh’s array means (A) roots symmetric about the origin (B) all roots real (C) instability (D) an arithmetic error.

Q28. One simple pole at the origin, others in the LHP: (A) stable (B) marginally stable (C) unstable (D) BIBO stable.

Answers: Q25 (A): \(2\cdot3>4\). Q26 (C): \(\varepsilon\)-case gives two sign changes (roots at \(e^{\pm j72^\circ}\) have positive real part). Q27 (A). Q28 (B).

22.8 Frequency response and Bode plots

Set 22.8

Q29. For \(\dfrac1{s(1+s/10)}\), the slope beyond \(\omega=10\) is (A) \(-20\) (B) \(-40\) (C) \(-60\) (D) \(0\) dB/dec.

Q30. \(G=\dfrac{100}{s+10}\): the low-frequency gain in dB is (A) \(10\) (B) \(20\) (C) \(40\) (D) \(100\).

Q31. PM is measured at (A) \(\omega_{pc}\) (B) \(\omega_{gc}\) (C) \(\omega=0\) (D) \(\omega_n\).

Q32. A pure delay \(e^{-sT}\) affects (A) magnitude only (B) phase only (C) both (D) neither.

Answers: Q29 (B). Q30 (B): \(DC=10\to20\) dB. Q31 (B). Q32 (B).

22.9 Root locus

Set 22.9

Q33. \(n-m=3\): asymptote angles are (A) \(0,120,240\) (B) \(60,180,300\) (C) \(45,135,225\) (D) \(90,270\).

Q34. A real-axis point is on the locus if the number of real poles and zeros to its right is (A) even (B) odd (C) zero (D) any.

Q35. Root-locus branches end at (A) poles (B) zeros (or infinity) (C) origin (D) \(-1\).

Q36. \(G=\dfrac{K(s+1)}{s(s+2)(s+3)}\): centroid is (A) \(-2\) (B) \(-2.5\) (C) \(-1\) (D) \(-4\).

Answers: Q33 (B). Q34 (B). Q35 (B). Q36 (A): \((-5+1)/2\).

22.10 Nyquist

Set 22.10

Q37. The Nyquist criterion \(Z=P+N\): \(N\) counts (A) CW encirclements of \(-1\) (B) CCW encirclements (C) poles (D) zeros.

Q38. \(P=1\), \(N=-1\): \(Z=\) (A) 0 (B) 1 (C) 2 (D) \(-1\).

Q39. If the plot crosses the negative real axis at \(-0.2\), GM is (A) \(0.2\) (B) \(5\) (C) \(-5\) (D) \(1.2\).

Q40. The critical point is (A) \(0\) (B) \(-1+j0\) (C) \(+1\) (D) \(j\).

Answers: Q37 (A). Q38 (A). Q39 (B): \(1/0.2\) (\(14\) dB). Q40 (B).

22.11 Controllers

Set 22.11

Q41. A PI controller (A) raises the type by one (B) lowers the type (C) leaves the type unchanged (D) improves phase margin.

Q42. Derivative action mainly improves (A) accuracy (B) damping (C) type (D) DC gain.

Q43. ZN ultimate-gain PID: \(K_p=\) (A) \(0.5K_u\) (B) \(0.6K_u\) (C) \(0.45K_u\) (D) \(K_u\).

Q44. A PID controller adds to the loop (A) 1 pole, 2 zeros (B) 2 poles, 1 zero (C) 1 pole, 1 zero (D) no poles.

Answers: Q41 (A). Q42 (B). Q43 (B). Q44 (A).

22.12 State-space models

Set 22.12

Q45. \(A=\begin{bmatrix}0&1\\-6&-5\end{bmatrix}\) has eigenvalues (A) \(-2,-3\) (B) \(2,3\) (C) \(-1,-6\) (D) \(-5,-6\).

Q46. \(\Phi(0)=\) (A) \(0\) (B) \(I\) (C) \(A\) (D) \(e\).

Q47. Controllable iff (A) \(\mathrm{rank}[B\ AB\dots]=n\) (B) \(\mathrm{rank}[C;CA;\dots]=n\) (C) \(|A|\neq0\) (D) \(A\) is diagonal.

Q48. \(G(s)=\) (A) \(C(sI-A)^{-1}B+D\) (B) \(C(sI+A)^{-1}B\) (C) \((sI-A)^{-1}\) (D) \(B(sI-A)^{-1}C\).

Answers: Q45 (A): \(\lambda^2+5\lambda+6\). Q46 (B). Q47 (A). Q48 (A).
