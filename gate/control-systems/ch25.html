25.1 Standard transfer functions and terms

Transfer functions

Integrator \(\frac1s\); differentiator \(s\); first order \(\frac{K}{\tau s+1}\); second order \(\frac{\omega_n^2}{s^2+2\zeta\omega_ns+\omega_n^2}\); delay \(e^{-sT}\).
\(G(s)=\mathcal L\{h(t)\}=\dfrac{Y(s)}{X(s)}\big|_{ICs=0}\); DC gain \(G(0)\); order \(=\deg(\text{denominator})\); type \(=\) number of poles of \(GH\) at \(0\).
Analogies: F–V: \(M\!\to\!L\), \(B\!\to\!R\), \(K\!\to\!1/C\). F–I: \(M\!\to\!C\), \(B\!\to\!1/R\), \(K\!\to\!1/L\).

25.2 Feedback

Key Formulae

\(T=\dfrac{G}{1+GH}\) (negative), \(\dfrac{G}{1-GH}\) (positive). \(S=\dfrac1{1+GH}\), \(S_G^T=S\), \(S_H^T=-\dfrac{GH}{1+GH}\), \(S+T=1\).
Disturbance: \(\dfrac CD=\dfrac{G_2}{1+G_1G_2H}\). First order with feedback: DC gain \(\dfrac K{1+K}\), \(\tau_{cl}=\dfrac\tau{1+K}\), bandwidth \(\dfrac{1+K}\tau\).

25.3 Block-diagram reduction

Key Formulae

Cascade: \(\prod G\); parallel: \(\sum G\); loop: \(\dfrac{G}{1\pm GH}\).
Take-off past \(G\) forward: branch \(\times\frac1G\); backward: \(\times G\). Summing point past \(G\) forward: branch \(\times G\); backward: \(\times\frac1G\).
Unity conversion: \(\dfrac{G}{1+GH}=\dfrac1H\cdot\dfrac{GH}{1+GH}\). Nested: \(\dfrac{G_1G_2G_3}{1+G_2H_1+G_1G_2G_3H_2}\).

25.4 Mason’s gain formula

Key Formulae

\(T=\dfrac{\sum P_k\Delta_k}{\Delta}\), \(\Delta=1-\sum L_i+\sum L_iL_j-\sum L_iL_jL_k+\cdots\) (non-touching sets); \(\Delta_k\): remove loops touching path \(k\).

25.5 Time response

First order

\(\dfrac1{\tau s+1}\): \(c=1-e^{-t/\tau}\); \(t_r(10\text{--}90)=2.2\tau\); \(t_d=0.69\tau\); \(t_s=4\tau\) (2%), \(3\tau\) (5%); ramp error \(\tau\).

Second order, \(0<\zeta<1\)

\(\omega_d=\omega_n\sqrt{1-\zeta^2}\); \(c=1-\dfrac{e^{-\zeta\omega_nt}}{\sqrt{1-\zeta^2}}\sin(\omega_dt+\cos^{-1}\zeta)\).
\(t_p=\dfrac\pi{\omega_d}\); \(M_p=e^{-\pi\zeta/\sqrt{1-\zeta^2}}\); \(t_r=\dfrac{\pi-\cos^{-1}\zeta}{\omega_d}\); \(t_s=\dfrac4{\zeta\omega_n}\) (2%), \(\dfrac3{\zeta\omega_n}\) (5%).
\(\zeta=\dfrac{-\ln M_p}{\sqrt{\pi^2+\ln^2M_p}}\); peak ratio \(e^{-2\pi\zeta/\sqrt{1-\zeta^2}}\). Standard: \(\zeta=0.5\to16.3\%\); \(0.707\to4.3\%\); \(0.6\to9.5\%\).

25.6 Steady-state error

Key Formulae

\(e_{ss}=\lim_{s\to0}\dfrac{sR(s)}{1+GH}\) (stable loop). \(K_p=GH(0)\), \(K_v=\lim sGH\), \(K_a=\lim s^2GH\).

25.7 Stability and Routh

Key Formulae

Stable \(\iff\) all closed-loop poles in the open LHP. Necessary: all coefficients present and of the same sign.
Routh: sign changes in the first column \(=\) RHP roots. Zero in the first column \(\to\varepsilon\); zero row \(\to\) auxiliary polynomial \(A(s)\), use \(dA/ds\).
Cubic \(a_3s^3+a_2s^2+a_1s+a_0\): stable \(\iff\) all \(>0\) and \(a_2a_1>a_3a_0\).

25.8 Frequency response, Bode and margins

Key Formulae

\(\omega_r=\omega_n\sqrt{1-2\zeta^2}\), \(M_r=\dfrac{1}{2\zeta\sqrt{1-\zeta^2}}\) (\(\zeta<0.707\)); \(\omega_b=\omega_n\sqrt{1-2\zeta^2+\sqrt{4\zeta^4-4\zeta^2+2}}\).
Bode slopes: \(-20\) dB/dec per pole, \(+20\) per zero; type \(N\) starts at \(-20N\); through \(20\log K\) at \(\omega=1\) (Bode form). Phase: pole \(0\to-90^\circ\) (\(-45^\circ\) at corner); integrator \(-90^\circ\); delay \(-\omega T\).
\(\mathrm{PM}=180^\circ+\angle GH(\omega_{gc})\); \(\mathrm{GM}=\dfrac{1}{|GH(\omega_{pc})|}\); \(\mathrm{PM}\approx100\zeta\). Quadratic-factor peak: \(-20\log(2\zeta\sqrt{1-\zeta^2})\) dB.

25.9 Root locus

Key Formulae

Angle: \(\angle GH=\pm180^\circ(2q+1)\); magnitude: \(K=\dfrac{\prod|s+p|}{\prod|s+z|}\). Real axis: odd count to the right. Asymptotes: \(n-m\); \(\theta=\dfrac{180^\circ(2q+1)}{n-m}\); \(\sigma_A=\dfrac{\sum p-\sum z}{n-m}\). Breakaway: \(\dfrac{dK}{ds}=0\). Departure: \(\phi_d=180^\circ-\sum\angle_p+\sum\angle_z\). Crossing: Routh/\(j\omega\).

25.10 Nyquist

Key Formulae

\(Z=P+N\) (\(N\): clockwise encirclements of \(-1\)). Stable \(\iff Z=0\). Type \(N\) polar plot starts at \(-90^\circ N\); indentation arc \(180^\circ N\) clockwise. GM \(=1/|\text{crossing on negative real axis}|\); PM at \(|GH|=1\).

25.11 Controllers and compensators

Key Formulae

P \(K_p\); PI \(K_p(1+\frac1{T_is})\); PD \(K_p(1+T_ds)\); PID \(K_p(1+\frac1{T_is}+T_ds)=\frac{K_ds^2+K_ps+K_i}{s}\).
ZN ultimate: PID \(K_p=0.6K_u\), \(T_i=P_u/2\), \(T_d=P_u/8\).
Lead \(\frac{1+aTs}{1+Ts}\): \(\phi_m=\sin^{-1}\frac{a-1}{a+1}\), \(\omega_m=\frac{1}{T\sqrt a}=\sqrt{zp}\), \(a=\frac{1+\sin\phi_m}{1-\sin\phi_m}\). Lag \(\frac{1+Ts}{1+\beta Ts}\): \(\omega_m=\frac{1}{T\sqrt\beta}\), high-frequency gain \(-20\log\beta\) dB.

25.12 State-space

Key Formulae

\(\dot x=Ax+Bu\), \(y=Cx+Du\), \(G=C(sI-A)^{-1}B+D\), poles \(=\mathrm{eig}(A)\).
CCF: last row of \(A=[-a_0\ -a_1\dots]\), \(B=[0\dots1]^T\), \(C=[b_0\ b_1\dots]\). OCF is the transpose.
\(\Phi(t)=e^{At}=\mathcal L^{-1}(sI-A)^{-1}\); \(\Phi(0)=I\), \(\dot\Phi(0)=A\), \(\Phi(t_1+t_2)=\Phi(t_1)\Phi(t_2)\), \(\Phi^{-1}(t)=\Phi(-t)\), \(\det\Phi=e^{\mathrm{tr}(A)t}\).
\(x(t)=\Phi(t)x_0+\int_0^t\Phi(t-\tau)Bu(\tau)d\tau\). Controllable: \(\mathrm{rank}[B\ AB\dots A^{n-1}B]=n\); observable: \(\mathrm{rank}[C;CA;\dots;CA^{n-1}]=n\).

Ten numbers to memorise

\(\zeta=0.5\to M_p=16.3\%\), \(\mathrm{PM}\approx50^\circ\).   \(\zeta=0.707\to M_p=4.3\%\), \(M_r\) absent.   \(t_s=4/\zeta\omega_n\).   \(63.2\%\) at \(\tau\).   \(\sin^{-1}\frac{a-1}{a+1}\): \(a=4\to37^\circ\), \(10\to55^\circ\).   \(K/[s(s+2)(s+4)]\): \(K_{max}=48\).   Cubic: \(a_2a_1>a_0\).   Bode: \(-20\) dB/dec \(\leftrightarrow-90^\circ\).   GM: \(1/|\text{crossing}|\).   RL: \((\sum p-\sum z)/(n-m)\).
