How to use this chapter

26.1 Open-loop vs closed-loop confusion

Trap

Poles of \(G(s)H(s)\) are open-loop poles; the closed-loop poles are the roots of \(1+GH=0\). Stability, \(\zeta\), \(\omega_n\), overshoot refer to the closed loop.

Example. \(G=\dfrac{16}{s(s+4)}\): the open-loop pole at \(0\) does not mean instability. Closed loop \(s^2+4s+16\): \(\zeta=0.5\), stable.

26.2 Forward path vs feedback path

Trap

\(H\) multiplies the feedback. The forward gain is \(G\) only; the loop gain is \(GH\). Error \(E=R-HC\) is the actuating error; the output error \(R-C\) is different when \(H\ne1\).

Example. \(G=\dfrac{10}{s(s+2)}\), \(H=0.5\): \(K_v\) of the loop is \(2.5\), but the closed-loop DC gain is \(1/H=2\) (for a type-1 loop the output follows \(R/H\)).

26.3 Sign convention in feedback

Trap

Negative feedback: \(\dfrac{G}{1+GH}\); positive: \(\dfrac{G}{1-GH}\). Mason: loop gains include the sign of the feedback branch; negative feedback gives \(L=-GH\) and \(\Delta=1+GH\).

Example. \(G=\dfrac{1}{s+1}\) with positive unit feedback: \(\dfrac{1}{s+1-1}=\dfrac1s\): an integrator (marginally stable).

26.4 Pole vs zero interpretation

Trap

Poles set the modes and stability; zeros only shape amplitudes. A RHP zero is not instability but non-minimum phase (undershoot, extra phase lag). A pole–zero cancellation in the RHP hides an unstable mode.

Example. \(\dfrac{s-1}{(s-1)(s+2)}\) simplifies to a stable \(\dfrac1{s+2}\), but the internal mode \(e^{t}\) remains.

26.5 System order vs system type

Trap

Order \(=\) number of poles (degree of denominator); type \(=\) number of poles at \(s=0\). \(\dfrac{1}{s(s+1)(s+2)}\): order 3, type 1. Type is defined on the open loop and controls steady-state error; order controls the number of state variables.

26.6 Stability vs steady-state error

Trap

The error formulas \(\dfrac1{K_v}\) etc. are valid only if the closed loop is stable. Raising gain lowers error but can destroy stability.

Example. \(G=\dfrac{K}{s(s+1)(s+2)}\): \(K_v=K/2\); for \(K=10\) the formula would give \(0.2\), but \(K_{max}=6\): the system is unstable and there is no steady state.

26.7 Phase margin vs gain margin

Trap

PM is read at \(\omega_{gc}\) (\(|GH|=1\)): \(180^\circ+\angle GH\). GM is read at \(\omega_{pc}\) (\(\angle GH=-180^\circ\)): \(1/|GH|\). Both must be positive (min-phase). A system with infinite GM can still have small PM. PM\(\approx100\zeta\) only for the standard second-order loop and small \(\zeta\).

26.8 Gain crossover vs phase crossover

Trap

Gain crossover is where the magnitude is \(1\) (0 dB); phase crossover is where the phase is \(-180^\circ\). Stability (min-phase): \(\omega_{gc}<\omega_{pc}\). Do not confuse either with the corner frequency or the closed-loop bandwidth.

26.9 Routh special cases

Trap

(a) A zero in the first column is replaced by \(\varepsilon\), never left as \(0\). (b) A row of zeros: form \(A(s)\) from the row above; replace by \(A'(s)\); the roots of \(A\) are exact roots of the polynomial. (c) After the array is completed, the sign changes in the whole first column still count the RHP roots; if the rows from \(A(s)\) downward show no sign change, the roots of \(A(s)\) lie on the \(j\omega\) axis (marginal), not in the RHP.

Example. \(s^3+2s^2+s+2=(s+2)(s^2+1)\): the \(s^1\) row is zero, \(A=2s^2+2\): roots \(\pm j\), marginal.

26.10 Root-locus angle condition

Trap

On the real axis: an odd number of poles/zeros to the right. Breakaway roots must lie on the locus. Departure angle: \(180^\circ\) minus pole angles plus zero angles. Centroid: \(\sum\)poles \(-\sum\)zeros over \(n-m\). Angles are measured to the point from each pole/zero (counter-clockwise from the positive real direction).

26.11 Nyquist encirclement direction

Trap

\(Z=P+N\) with \(N\) counting clockwise encirclements of \(-1\). Flip to \(N_{ccw}\) and you need \(Z=P-N_{ccw}\). The mirror image for \(\omega<0\) doubles the encirclements; poles at the origin add a \(180^\circ N\) clockwise arc at infinity. The critical point is \(-1\), not the origin.

26.12 PID effects

Trap

Integral removes the steady-state error but reduces stability and slows the response; derivative improves damping but amplifies noise and does not change steady-state error; proportional reduces (does not remove) error. A PI adds a pole at the origin, so it raises the type by one; PD leaves the type unchanged.

26.13 Controllability vs observability

Trap

Controllability: rank\([B\ AB\dots]\) (input \(\to\) state). Observability: rank\([C;CA;\dots]\) (state \(\to\) output). Neither implies the other. Pole–zero cancellation kills one or both. CCF is always controllable; OCF is always observable. Repeated eigenvalues with a single input in diagonal form are uncontrollable even if no row of \(B\) is zero.

Quick self-test

Q1. \(G=\dfrac{25}{s(s+5)}\), unity feedback: is the closed-loop \(\zeta\) found from the open-loop poles \(0,-5\)? (A) yes, \(\zeta=0.5\) (B) no, from \(s^2+5s+25\) (C) yes, \(\zeta=1\) (D) no, undefined.

Q2. PM is read at (A) \(\omega_{pc}\) (B) \(\omega_{gc}\) (C) \(\omega_n\) (D) \(\omega=0\).

Q3. \(Z=P+N\); \(P=0\), \(N=2\): closed-loop RHP poles \(=\) (A) 0 (B) 2 (C) 4 (D) \(-2\).

Answers: Q1 (B): \(\zeta=5/(2\cdot5)=0.5\) obtained from the closed-loop polynomial. Q2 (B). Q3 (B).
