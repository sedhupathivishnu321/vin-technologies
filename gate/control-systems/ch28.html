How to use these tests

Twelve tests: eleven topic tests (Tests 1–11, each \(12\) marks, \(\approx15\) minutes) and one complete mock (Test 12, \(30\) marks, \(\approx45\) minutes). All problems are original, written in the style of GATE ECE. MCQ: \(-\frac13\) (1-mark) and \(-\frac23\) (2-mark) for a wrong answer; NAT and MSQ: no negative marking (MSQ needs all correct options). Answer keys with brief reasoning follow each test.
