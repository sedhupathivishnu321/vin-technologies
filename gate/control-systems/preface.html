Preface: How to Use This Book

chapterPreface: How to Use This Book

Control Systems carries roughly \(8\)–\(10\) marks in GATE ECE, and it is one of the most predictable subjects: the same dozen question types (Mason’s gain, second-order specifications, error constants, Routh range of \(K\), Bode margins, root-locus features, Nyquist encirclements, state-transition matrix) recur every year. The book takes you from modelling to state space in fourteen parts, following the natural order

modelling \(\to\) transfer functions \(\to\) feedback \(\to\) time response \(\to\) steady-state error \(\to\) stability \(\to\) frequency response \(\to\) root locus / Nyquist \(\to\) controller design \(\to\) state space.

Every chapter has the same anatomy:

Core Concept \(\to\) Derivation \(\to\) Standard Results \(\to\) Physical Interpretation \(\to\) Solved Examples \(\to\) 1-Mark \(\to\) 2-Mark \(\to\) NAT \(\to\) Previous-Year Pattern \(\to\) Traps \(\to\) Shortcuts \(\to\) Chapter Test \(\to\) One-Page Revision

  • Boxes. Blue = formulae, orange = solved examples, green = GATE shortcuts, red = conceptual traps, grey = derivations, violet/indigo/teal/magenta = 1-mark, 2-mark, NAT, MSQ; yellow = chapter test and one-page revision.
  • Figures (block diagrams, step responses, Bode, root-locus and Nyquist plots) are computed from the actual transfer functions, not sketched by hand.
  • Answers follow each problem set, with the working in brief.
Important note on the “previous-year” problems

All problems in the 1-mark, 2-mark, NAT, MSQ, “previous-year pattern” and mock-test sections are original problems written to match the style, difficulty and recurring ideas of past GATE ECE papers. They are not verbatim copies of official questions, and no year or question number is attached to any of them. Chapter 27 is organised as a topic-wise map of what GATE repeatedly asks; for the official questions themselves, download the papers from the GATE organising institute and use this book as the solution toolkit.

Conventions. \(G(s)\) forward-path transfer function, \(H(s)\) feedback-path, \(G(s)H(s)\) the open-loop transfer function; negative feedback is assumed unless stated. \(\omega_n\) natural frequency, \(\zeta\) damping ratio, \(\omega_d=\omega_n\sqrt{1-\zeta^2}\). \(\omega_{gc}\) gain-crossover, \(\omega_{pc}\) phase-crossover frequency. \(\mathrm{PM}\), \(\mathrm{GM}\) phase and gain margin. Logs in dB are \(20\log_{10}|\cdot|\). “Type” is the number of open-loop poles at \(s=0\); “order” is the degree of the characteristic polynomial.
