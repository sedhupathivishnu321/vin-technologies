13.1 Sample-and-hold

A sample-and-hold (S/H) circuit tracks the input while the switch is closed (sample mode) and freezes it on a capacitor when the switch opens (hold mode), so that an ADC sees a constant value during conversion. A buffer amplifier isolates the capacitor at the input and output.

  • Acquisition time: time for the capacitor to charge to within the specified error after the switch closes (\(\approx n\ln2\cdot R_{on}C\) for \(n\)-bit accuracy).
  • Aperture time/jitter: uncertainty in the instant of sampling; limits the maximum input frequency.
  • Droop rate: \(\dfrac{dV}{dt}=\dfrac{I_{leak}}{C_H}\) during hold.
  • Feedthrough, charge injection (pedestal error) from the switch.

Larger \(C_H\) means less droop but slower acquisition.

13.2 Quantization

An \(n\)-bit converter with full-scale range \(V_{FS}\) resolves

Resolution

\(\text{LSB}=\dfrac{V_{FS}}{2^n}\) (for a range \([0,V_{FS}]\) with \(2^n\) steps). Number of levels \(2^n\); percentage resolution \(=\dfrac1{2^n-1}\times100\%\).
Quantization error \(\in[-\tfrac12\text{LSB},+\tfrac12\text{LSB}]\) (rounding quantizer), rms \(=\text{LSB}/\sqrt{12}\).
Ideal SQNR for a full-scale sine: \(\text{SQNR}=6.02\,n+1.76\ \text{dB}\).

Sampling must satisfy \(f_s\ge2f_{max}\) (Nyquist); an anti-aliasing filter precedes the S/H.

13.3 Digital-to-analog converters

13.3.1 Binary-weighted resistor DAC

Resistors \(R,2R,4R,\dots,2^{n-1}R\) switch the reference into the summing node of an inverting op-amp: \(V_o=-R_fV_{ref}\sum_{i}\dfrac{b_i}{R_i}\). It needs a wide resistor ratio (\(2^{n-1}\)) which limits accuracy for large \(n\).

13.3.2 R-2R ladder DAC

Only two resistor values are used; the ladder halves the current at each node. In the voltage-mode (non-inverting) version

R-2R ladder

\(V_{out}=V_{ref}\displaystyle\sum_{i=0}^{n-1}\frac{b_i}{2^{\,n-i}}=V_{ref}\,\frac{N}{2^n}\), where \(N\) is the binary input read as an integer. Full scale \(=V_{ref}\,(1-2^{-n})\). With an inverting op-amp stage the output is \(-V_{ref}N/2^n\) (times the gain).

Solved Example

4-bit R-2R, \(V_{ref}=8\,\)V, input \(1011_2=11\): \(V_{out}=8\times11/16=5.5\,\)V. LSB \(=0.5\,\)V, full scale \(7.5\,\)V.
10-bit, \(V_{ref}=10\,\)V: LSB \(=9.766\,\)mV, full scale \(9.990\,\)V.

Performance terms: offset, gain error, DNL (deviation of a step from 1 LSB; monotonic if \(\text{DNL}>-1\) LSB), INL (deviation from the ideal straight line), settling time and glitch energy.

13.4.1 Successive approximation

Starting from the MSB, set each bit to 1, compare the DAC output with \(V_{in}\) and keep the bit if \(V_{DAC}\le V_{in}\). Exactly \(n\) clock cycles regardless of the input value.

8-bit SAR, \(V_{ref}=5\,\)V, \(V_{in}=3.2\,\)V

LSB \(=19.53\,\)mV; the final code is \(\lfloor3.2/0.01953\rfloor=163\). Trial sequence: \(10000000\) (2.5 V, keep), \(11000000\) (3.75 V, drop), \(10100000\) (3.125 V, keep), \(10110000\) (drop), \(10101000\) (drop), \(10100100\) (3.203 V \(>3.2\), drop), \(10100010\) (keep), \(10100011\) (3.184 V, keep). Result \(10100011=163\).

13.4.2 Dual-slope

The input is integrated for a fixed time \(T_1=2^nT_{clk}\), then the integrator is discharged by \(-V_{ref}\) in time \(T_2\): \(T_2=T_1\,V_{in}/V_{ref}\), so the count is proportional to \(V_{in}\) and independent of \(R\), \(C\) and clock stability (to first order). Choosing \(T_1\) as a multiple of the mains period (20 ms) rejects 50 Hz pickup.

13.4.3 Flash

A resistor string of \(2^n\) equal resistors generates \(2^n-1\) thresholds; one comparator per threshold; a priority encoder converts the thermometer code to binary. \(n=8\): 255 comparators. Hardware doubles with each added bit.

Conceptual Trap

(i) A flash ADC needs \(2^n-1\) comparators, not \(2^n\). (ii) SAR conversion time is \(n\) clocks, independent of input. (iii) Counter-ADC time depends on the input amplitude (up to \(2^n\) clocks). (iv) Full-scale output of an \(n\)-bit DAC is \(V_{ref}(1-2^{-n})\), not \(V_{ref}\). (v) SQNR \(6.02n+1.76\) dB holds for a full-scale sinusoid only.

GATE Shortcut

LSB \(=V_{FS}/2^n\); code \(=\lfloor V_{in}/\text{LSB}\rfloor\). DAC output \(=\text{LSB}\times N\). Speed order: flash \(>\) SAR \(>\) counter \(>\) dual-slope. Each extra bit adds 6 dB of SQNR.

13.5 GATE problems

GATE 1-Mark Problems

Q1. Comparators in a 6-bit flash ADC: (A) 6 (B) 32 (C) 63 (D) 64.

Q2. The conversion time of an \(n\)-bit SAR ADC with clock \(f_c\) is (A) \(2^n/f_c\) (B) \(n/f_c\) (C) \(1/f_c\) (D) \(n^2/f_c\).

Q3. The resolution (LSB) of a 10-bit DAC with a 5 V full-scale range: (A) 4.88 mV (B) 9.77 mV (C) 0.5 V (D) 1 mV.

Q4. The fastest ADC type is (A) dual-slope (B) counter (C) flash (D) SAR.

Answers: Q1 (C). Q2 (B). Q3 (A): \(5/1024=4.883\,\)mV. Q4 (C).

GATE 2-Mark Problems

Q5. A 4-bit R-2R DAC with \(V_{ref}=8\,\)V receives \(1011\). The output is (A) 5.0 V (B) 5.5 V (C) 6.0 V (D) 11 V.

Q6. A 10-bit counter-type ADC is clocked at 2 MHz. Maximum conversion time: (A) 5 \(\mu\)s (B) 512 \(\mu\)s (C) 1024 \(\mu\)s (D) 256 \(\mu\)s.

Q7. An 8-bit ADC with 5 V full scale converts 3.2 V. The output code is (A) 10100000 (B) 10100011 (C) 10100100 (D) 11001000.

Answers: Q5 (B). Q6 (B): \(1024/(2\times10^6)=512\,\mu\)s. Q7 (B): \(163\).

Numerical Answer Type (NAT)

Q8. A hold capacitor droops at \(I_{leak}/C_H\) with \(I_{leak}=1\,\)nA and \(C_H=10\,\)pF. Droop over 20 \(\mu\)s (mV): .

Q9. Ideal SQNR of a 12-bit ADC (dB): .

Q10. Maximum conversion time of an 8-bit dual-slope ADC clocked at 100 kHz (\(T_1+T_2\) with \(T_2\le T_1=2^n\) clocks), in ms: .

Answers: Q8: \(dV/dt=100\,\)V/s; \(\times20\,\mu\)s \(=2\,\)mV. Q9: \(6.02\times12+1.76=74.0\). Q10: \(2\times256/10^5=5.12\).

Multiple Select (MSQ)

Q11. Select the true statements. (A) A flash ADC needs \(2^n-1\) comparators. (B) SAR conversion time depends on the input. (C) Dual-slope converters can reject mains interference. (D) The R-2R DAC needs only two resistor values.

Answers: Q11: (A), (C), (D).

Chapter Test

T1. LSB of a 12-bit, 4.096 V ADC.   T2. Bits needed for SQNR \(\ge60\,\)dB.   T3. Comparators in 4-bit flash.

Answers: T1: 1 mV. T2: \((60-1.76)/6.02=9.68\to10\) bits. T3: 15.
