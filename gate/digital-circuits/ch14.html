14.1 Instruction set architecture

An instruction has an opcode and zero to three operand fields. The number of addresses decides code size and register use.

\(X=(A+B)\times(C+D)\)

3-address: ADD R1,A,B; ADD R2,C,D; MUL X,R1,R2 \(\to\) 3 instructions.
2-address: MOV R1,A; ADD R1,B; MOV R2,C; ADD R2,D; MUL R1,R2; MOV X,R1 \(\to\) 6.
1-address: LOAD A; ADD B; STORE T; LOAD C; ADD D; MUL T; STORE X \(\to\) 7.
0-address: PUSH A; PUSH B; ADD; PUSH C; PUSH D; ADD; MUL; POP X \(\to\) 8.

RISC vs CISC. RISC: fixed-length instructions, load/store architecture (only LOAD/STORE touch memory), many registers, simple addressing modes, easy to pipeline. CISC: variable length, memory operands in arithmetic instructions, complex addressing, microcoded.

Performance

CPU time \(=\text{IC}\times\text{CPI}\times T_{clk}=\dfrac{\text{IC}\times\text{CPI}}{f}\). MIPS \(=\dfrac{f}{\text{CPI}\times10^6}\).
Average CPI \(=\sum_i f_i\,\text{CPI}_i\) over instruction classes with frequency \(f_i\).

14.2.1 Instruction encoding

For a 32-bit instruction word with an 8-bit opcode and two 5-bit register fields the remaining \(32-8-10=14\) bits hold an immediate: signed range \(-2^{13}\ldots2^{13}-1\). A \(k\)-bit opcode encodes at most \(2^k\) operations. For a PC-relative branch with a 16-bit signed word offset the reach is \(\pm2^{15}\) instructions. Expanding opcodes lets short-operand instructions use unused opcode patterns of long ones.

14.3 The ALU and the data path

The ALU (Chapter 5) performs arithmetic and logic on two operands and sets the flags \(Z,N,C,V\). The data path comprises the program counter (PC), instruction register (IR), register file, ALU, memory address and data registers (MAR/MDR) and the buses/multiplexers joining them.

Instruction cycle (multicycle view).

  1. Fetch: \(MAR\leftarrow PC\), \(IR\leftarrow M[MAR]\), \(PC\leftarrow PC+4\).
  2. Decode and register read.
  3. Execute (ALU operation or address computation).
  4. Memory access (load/store).
  5. Write back to the register file.

A single-cycle design executes each instruction in one (long) clock with \(T_{clk}\) equal to the slowest instruction; a multicycle design uses a shorter clock and a different number of cycles per instruction.

14.4 Control unit

  • Hardwired: combinational logic/FSM generates control signals from the opcode and state; fast, hard to modify.
  • Microprogrammed: each machine instruction is a sequence of microinstructions stored in a control memory (ROM); flexible, slower.

A horizontal microinstruction has one bit per control signal (wide, fast, parallel). A vertical microinstruction encodes mutually exclusive signals in fields: a field controlling \(k\) exclusive signals needs \(\lceil\log_2(k+1)\rceil\) bits (the extra code is “no signal”). Control-store size \(=\) (number of microinstructions) \(\times\) (word width).

Vertical encoding

Groups of \(3,7,12,5\) mutually exclusive signals need \(2+3+4+3=12\) bits versus \(27\) bits horizontally.

14.5 Instruction pipelining

The classic five stages are IF, ID, EX, MEM, WB. Overlapping instructions raises throughput while single-instruction latency is unchanged (or worse).

Pipeline performance

\(k\) stages, \(n\) instructions, ideal stage time \(T\): time \(=(k+n-1)\,T\); non-pipelined \(=nkT\).
Speed-up \(=\dfrac{nk}{k+n-1}\to k\) as \(n\to\infty\).
Clock period \(=\max(\text{stage delays})+t_{reg}\). Pipeline CPI \(=1+\text{stall cycles per instruction}\).
Branch effect: CPI \(=1+f_{br}\times\text{penalty}\) (if every branch pays the penalty).

14.5.1 Hazards

  • Structural: two instructions need the same resource (e.g. a single memory port). Fix: duplicate resources (separate instruction and data memories).
  • Data: RAW (read after write, true dependence), WAR (anti-dependence) and WAW (output dependence). In an in-order pipeline only RAW causes stalls. Fixes: forwarding (bypassing), compiler scheduling, interlocks. A load followed immediately by a user of the loaded register still needs one stall cycle even with forwarding. Without forwarding (writes in the first half of WB, reads in the second half of ID) a dependent instruction right behind needs 2 stall cycles.
  • Control: branches change the PC. Fixes: stall, predict not taken/taken, delayed branch, branch prediction.
Speed-up with unbalanced stages

Stage delays 200, 150, 250, 200, 100 ps with 20 ps register overhead. Pipeline clock \(=250+20=270\,\)ps. Non-pipelined delay \(=900\,\)ps. Ideal speed-up \(=900/270=3.33\) (not 5, because of imbalance and overhead).

Stalls

Loads are 20% and 50% of them are followed by a dependent instruction (1 stall each); branches are 15% with a 2-cycle penalty. CPI \(=1+0.2\times0.5\times1+0.15\times2=1.4\).

Conceptual Trap

(i) Indirect addressing costs an extra memory access. (ii) Pipelining does not reduce the latency of one instruction. (iii) The pipeline clock is set by the slowest stage, not the average. (iv) Forwarding does not eliminate the load-use stall. (v) Speed-up \(\to k\) only for large \(n\) and no stalls.

GATE Shortcut

Pipelined time \(=(k+n-1)T\). Memory references for an instruction with indirect addressing \(=1\) (fetch) \(+2\). \(n\)-address expression counting: group intermediate results in registers (3-address) or temporary memory (1-address).

14.6 GATE problems

GATE 1-Mark Problems

Q1. In indirect addressing the operand address is (A) in the instruction (B) in a register (C) in the memory location whose address is in the instruction (D) PC plus offset.

Q2. The ideal speed-up of a \(k\)-stage pipeline for \(n\to\infty\) instructions is (A) \(k\) (B) \(k-1\) (C) \(1\) (D) \(k^2\).

Q3. Which hazard needs a stall even with forwarding? (A) ALU–ALU RAW (B) load–use RAW (C) WAR (D) WAW in an in-order pipeline.

Q4. A hardwired control unit differs from a microprogrammed one in being (A) slower (B) faster and less flexible (C) larger memory (D) vertical.

Answers: Q1 (C). Q2 (A). Q3 (B). Q4 (B).

GATE 2-Mark Problems

Q5. A 5-stage pipeline with 2 ns stages executes 100 instructions without stalls. The speed-up over a non-pipelined machine (10 ns per instruction) is (A) 4.81 (B) 5.00 (C) 4.00 (D) 3.33.

Q6. The 32-bit instruction format has an 8-bit opcode and two 5-bit register fields; the rest is a signed immediate. The immediate range is (A) \(-2^{13}\) to \(2^{13}-1\) (B) \(-2^{14}\) to \(2^{14}-1\) (C) \(0\) to \(2^{14}\) (D) \(-2^{12}\) to \(2^{12}-1\).

Q7. A 2-address machine evaluates \(X=(A+B)\times(C+D)\) in (A) 3 (B) 4 (C) 6 (D) 8 instructions (with MOV allowed).

Answers: Q5 (A): \((5+99)\cdot2=208\,\)ns; non-pipelined \(1000\,\)ns; \(1000/208=4.81\). Q6 (A): 14-bit field. Q7 (C).

Numerical Answer Type (NAT)

Q8. Stage delays 200, 150, 250, 200, 100 ps, register overhead 20 ps. Pipelined clock frequency (GHz, two decimals): .

Q9. Ideal CPI \(=1\); 25% of instructions are branches, each costing 3 stall cycles (always taken). The CPI is .

Q10. Number of memory accesses to fetch and execute a LOAD with indirect addressing (instruction fetch counted): .

Answers: Q8: \(1/270\,\)ps \(=3.70\) GHz. Q9: \(1+0.25\times3=1.75\). Q10: 3.

Multiple Select (MSQ)

Q11. Which are true? (A) RAW is a true dependence. (B) Forwarding removes all stalls. (C) RISC machines use load/store architecture. (D) PC-relative addressing supports position-independent code.

Answers: Q11: (A), (C), (D).

Chapter Test

T1. EA in base-register mode with \(R=2000\), \(d=48\)?   T2. Speed-up of 4 stages for 13 instructions.   T3. CPI formula with branch penalty.

Answers: T1: 2048. T2: \(4\cdot13/(4+12)=3.25\). T3: \(1+f_{br}\times\)penalty.
