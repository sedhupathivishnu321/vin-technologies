4-bit binary counter

Digital Systems Lab · free online experiment, runs in your browser with no install or sign-up.

Open this experiment in the circuit simulator

Objective

Count 16 clock pulses with a 4-bit synchronous counter and read the binary count on four probes.

Procedure

  1. Run and read Q3 Q2 Q1 Q0 after each rising edge.

Theory

Q0 toggles every clock, Q1 every 2nd, Q2 every 4th, Q3 every 8th: the outputs count 0000 … 1111 and wrap round. Each output is the clock divided by 2, 4, 8, 16.

Questions to answer

  1. What is the modulus of this counter?

Components used

4-bit binary counter, Clock source, 4 × Logic probe / LED, Logic switch

About the model

Ideal wires; component models as listed in the catalogue (no parasitics, no temperature drift). Built without a breadboard so the schematic stays readable.
