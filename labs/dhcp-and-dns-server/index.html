DHCP and DNS server

Routing and security · free online experiment, runs in your browser with no install or sign-up.

Open this experiment in the network simulator

Objective

Two PCs get addresses from a DHCP server, then look up a name on the DNS server.

Procedure

  1. Run: the Summary tab lists the leases and the DNS answers.
  2. Open Packet capture and follow the four DHCP messages.

Theory

DHCP: DISCOVER (broadcast) → OFFER → REQUEST → ACK. The ACK carries the address, mask and gateway. DNS: a UDP query on port 53 returns the A record, or NXDOMAIN if the name is unknown.

Network blocks used

2 × Host / PC, Server (DNS + DHCP), Switch
