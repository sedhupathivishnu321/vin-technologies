File transfer over TCP: LAN versus WAN

Computer Networks Lab · free online experiment, runs in your browser with no install or sign-up.

Open this experiment in the network simulator

Objective

Copy a 500 kB file across a fast LAN and across a slow, long WAN link and compare the times.

Procedure

  1. Run and compare the two TCP lines in the Summary.
  2. Raise the WAN link to 10 Mbit/s and compare again.

Theory

Transfer time ≈ size / goodput. On the LAN the 100 Mbit/s link and 1 ms delay keep the pipe full; on a 2 Mbit/s link with 40 ms delay the rate limit and the window dynamics dominate.

Network blocks used

3 × Host / PC, Router, Switch
