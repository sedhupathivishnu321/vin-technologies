Kirchhoff's voltage law

Basic Electrical Lab · free online experiment, runs in your browser with no install or sign-up.

Open this experiment in the circuit simulator

Objective

Verify that the voltage drops around a loop add up to the source voltage.

Procedure

  1. Run and add the three drops.
  2. Reverse the battery: all drops change sign.

Theory

KVL: Σ V = 0 around any closed loop. 12 V = I·(1 k + 2.2 k + 4.7 k) with I = 1.519 mA.

Questions to answer

  1. Which resistor takes most of the voltage?

Components used

Battery / DC source, 3 × Resistor 220 ohm 1/4W

About the model

Ideal wires; component models as listed in the catalogue (no parasitics, no temperature drift). Built without a breadboard so the schematic stays readable.
