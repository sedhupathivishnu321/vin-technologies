Norton's theorem

Basic Electrical Lab · free online experiment, runs in your browser with no install or sign-up.

Open this experiment in the circuit simulator

Objective

Replace the same network by IN in parallel with Rth and compare the load current.

Procedure

  1. Run and read the load current of R4.
  2. Compare with the Thevenin experiment.

Theory

IN = Vth/Rth = 8 V / 1.1667 kΩ = 6.857 mA. The load takes IN·Rth/(Rth+RL).

Questions to answer

  1. How are Thevenin and Norton equivalents related?

Components used

DC current source, 2 × Resistor 220 ohm 1/4W

About the model

Ideal wires; component models as listed in the catalogue (no parasitics, no temperature drift). Built without a breadboard so the schematic stays readable.
