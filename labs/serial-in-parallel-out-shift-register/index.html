Serial-in parallel-out shift register

Digital Systems Lab · free online experiment, runs in your browser with no install or sign-up.

Open this experiment in the circuit simulator

Objective

Shift the serial word 1 0 1 1 into a 4-bit register and read it in parallel.

Procedure

  1. Run and watch the bits move one place per clock.
  2. Read the register after the fourth edge.

Theory

On every rising edge each stage copies its neighbour and Q0 takes the serial input, so after 4 clocks the first bit has reached Q3: Q3 Q2 Q1 Q0 = 1 0 1 1.

Questions to answer

  1. How do you convert parallel data back to serial?

Components used

4-bit shift register, Clock source, 4 × Logic probe / LED, Logic switch

About the model

Ideal wires; component models as listed in the catalogue (no parasitics, no temperature drift). Built without a breadboard so the schematic stays readable.
