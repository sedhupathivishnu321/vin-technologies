Switched LAN: ping and ARP

Local networks · free online experiment, runs in your browser with no install or sign-up.

Open this experiment in the network simulator

Objective

Three PCs on one switch. H1 pings H2; watch ARP resolution and MAC learning in the capture.

Procedure

  1. Press Run.
  2. Open Packet capture: the first lines are ARP who-has / is-at, then ICMP echo request / reply.
  3. Select the link H1–SW and change its delay to 5 ms; run again and compare the RTT.

Theory

The first packet triggers an ARP broadcast (flooded by the switch). The reply teaches the switch where H1 and H2 are, so later frames are forwarded only to the right port. RTT = 2 × hops × (frame bits / rate + propagation delay), plus the switch's few microseconds.

Network blocks used

3 × Host / PC, Switch
