Wi-Fi access point

Local networks · free online experiment, runs in your browser with no install or sign-up.

Open this experiment in the network simulator

Objective

A phone and a laptop join the wired LAN through an access point (slower, lossier wireless links).

Procedure

  1. Run: the phone's ping crosses the 54 Mbit/s wireless hop and the wired hop.
  2. Select the phone link and raise Loss to 10 %: some pings are lost.

Theory

The access point bridges wireless clients onto the wired segment. Wireless links are modelled as point-to-point links with their own rate, delay and loss; no 802.11 contention.

Network blocks used

Access point, 2 × Host / PC, Server (DNS + DHCP)
